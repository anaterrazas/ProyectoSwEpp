Desconocido no significa ausente. Los reflejos y oclusiones pueden impedir evaluar daños. PASS solo describe umbrales técnicos.

Requisitos para cerrar esta muestra

Son los campos de evaluabilidad, otros defectos y conclusión que exige el cierre. Desconocido permite guardar un borrador; no se transforma automáticamente en Sí o No.

    Evaluabilidad · visibilidad suficiente

    Decida explícitamente si la imagen permite evaluar el cuerpo. Es obligatorio decidir Sí o No para cerrar.

    Si la tapa no es suficientemente visible, indique No y mantenga sus defectos desconocidos.

    Defectos · admite varios presentes
    Otros defectos · decisión requerida para cerrar

    Este campo es independiente de los tres defectos anteriores. Revise lo observable y decida Sí o No; no seleccione No por defecto. Si todavía no puede decidir, conserve Desconocido y el borrador.

    Conclusión humana · categorías requeridas para cerrar

    Decida ambas categorías explícitamente. CONFORME exige todos los defectos ausentes y regiones evaluables. NO_EVALUABLE puede coexistir con un defecto visible.

    El cierre requiere un revisor distinto del anotador inicial. La identidad se declara localmente; no es una sesión de Django.
